无尽之梦 — A2A 潜意识社交

Second Me A2A 黑客松参赛作品。基于 A2A 协议的梦境交换应用——每天清晨录下梦境，你的 Agent 分身会带着它去和陌生人的 Agent 相遇，用对方最陌生的碎片重新编织你的梦。傍晚归来时，你的梦已不是你记得的样子。

核心哲学：陌生性交换，而非相似性共鸣。

Omphalina — 人造化合物历史模拟器

Omphalina 是一款运用 Gemini 3 flash实时生成的历史互动叙事游戏。玩家扮演历史关键节点的人造化合物创造者，通过选项决策，探索人造化合物（合成氨、DDT、青霉素、氟利昂等）从"拯救人类"走向不可预知后果的历程。

项目核心理念：人造化合物的发现承载着进步与混沌碰撞的"奇点"。技术上采用基于事实的化学知识库和基于历史推演的世界线编织架构，结合 Gemini 实时生成第一人称叙事与炭笔素描视觉，让玩家在每次选择中感受蝴蝶效应与科技双刃剑的深刻隐喻。

Context English

基于 AI 的英语学习工具，核心理念是"拒绝硬记，在情景中背单词"。提供三种学习模式：
1. 例句模式 - 为单词生成真实语境的例句
2. 记忆模式 - 创造趣味故事或笑话，并配AI生成插图加深记忆
3. 场景模式 - 分析上传照片中的场景，学习相关词汇

应用自动提取并展示单词的发音、释义、搭配、同义词和词根词缀。采用 React + TypeScript 前端和 Node.js 后端架构，支持历史记录管理，让英语学习更加生动高效。

详细介绍
事实距离器

一个将观点与档案事实进行对比的工具。通过语义检索档案库和网络公开信息，结合大语言模型分析，以结构化方式呈现观点与事实间的差异（矛盾、缺失上下文、表述偏差、无法验证），不做价值判断。

核心理念：让读者自己看到差异，自己掌握获得观点的权利。适用于任何需要事实核查的文本分析场景。

自动化采集工具

通过图像识别和鼠标模拟技术，自动浏览指定网页并批量采集公开数据。脚本会自动识别屏幕图标、点击菜单、复制数据，并实时保存到CSV文件中。支持增量采集，遇到已采集的旧数据会自动停止。内置防重复机制和原地踏步补救功能。配置简单，无需编程基础，适合运营人员日常数据收集使用。
